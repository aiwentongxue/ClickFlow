## 本机迁移与界面

- 通过打包后的正式 app，将匹配官方旧副本复制到 `~/Library/Application Support/ClickFlow/OJD/OpenJoystickDriver.app`，更新私有 `ojd` 链接。
- 旧服务运行时连接被明确拒绝并显示实际路径；取消切换不退出旧服务。
- 实测发现官方 CLI 会将包外 `ojd` 链接转发到 `/Applications` 安装。现为 ClickFlow 的 CLI 与 feed 设置官方 `OJD_RUN_REPOSITORY_CLI=1`，关闭此转发，保留官方原包。
- 显式切换后，以真实进程路径确认官方服务从 Application Support 运行；系统权限仍为 Granted。连接得到系统虚拟手柄，重复安装复用新副本。
- Finder 定位到新目录；“输入监控”按钮定位正确页面；复制路径与权限说明使用新路径。中英文页面已检查。
- 新副本保持官方 Team `9PQP6CDMQT` 与 `com.apple.developer.hid.virtual.device = true`，通过严格签名检查及系统信任评估。未重签 OJD、未注册 USB 扩展、未更改系统保护或登录项。

## 游戏复测

测试游戏：本机原生《无限暖暖》，2.11.1（2884）；通过正式 ClickFlow 播放手柄宏。

- 已有实体手柄时游戏先接收实体设备；断开实体设备仍未切换。保持 OJD 连接、实体手柄关闭并重新启动游戏后，虚拟 A 键成功触发进入游戏，镜头宏正常转动。
- 该游戏没有手柄设备选择，因此使用“先连接虚拟手柄、再启动游戏”的顺序。测试期间不消耗游戏资源。
- 镜头宏：0.9 右摇杆值，用户确认正常转动；系统探针读到约 0.86。暂停后镜头停住。
- 重新连接实体 Xbox 后，固定新的实体来源再连接 OJD。用户确认实体左摇杆移动和宏镜头转动同时正常。探针在虚拟设备同一帧读到实体左摇杆与宏右摇杆；暂停后用户确认实体右摇杆控制恢复，松开停住。
- 用户确认恢复镜头宏后再次转动，菜单栏“紧急停止”后停止。
- 移动 + A 跳跃宏运行三轮，用户确认前后移动、跳跃及结束释放均正常；Menu / Start 短按宏主菜单正常响应。按钮“停止”后宏退出。
- 游戏复测通过后，通过管理页勾选验收项并将旧副本移到废纸篓。`/Applications/OpenJoystickDriver.app` 已不存在，废纸篓原包仍通过严格签名验证。没有处理其他路径副本。
- 旧副本清理后，断开与重新连接均成功；新连接探针中按钮和双摇杆为中性。退出 ClickFlow 后，其私有 feed 和虚拟设备消失，Application Support 中的 OJD 共享服务仍运行。游戏也已正常退出。

本轮真实游戏测试为 Apple Silicon 上的《无限暖暖》。Intel 架构已构建验证，未在 Intel 硬件实测；其他游戏按各自设备识别逻辑使用。XInput 自动化回归通过，本轮未运行 Windows 游戏人工集成测试。
