## 使用条件与覆盖范围

小幅摇杆可能落在系统或游戏死区：本机宏值 0.4 被 GameController 读取为约 0.18，镜头未动；0.9 被读取为约 0.86，镜头正常。先用较大幅度确认，再调整宏值和游戏死区。

首次测试中游戏只响应原有实体手柄。可用测试路径包含先连接 OJD 再启动游戏；游戏没有设备选择菜单。ClickFlow 不提供系统级隐藏实体设备；其他游戏仍应分别验收多设备与重复输入。

中英文界面已检查。未对 Intel 真机、PlayCover、SDL 游戏或 Windows 游戏重新进行实机兼容测试，XInput 回归以现有自动化为准。

本次仅本地交付，不推送远端、不发布 Release。OJD 仍是独立的官方签名组件，由 ClickFlow 提供一键安装与连接管理。
